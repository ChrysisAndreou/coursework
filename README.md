# AI/ML Coursework Portfolio

Selected coursework from the MSc Artificial Intelligence program at the University of Cyprus. The repository is organized by subject and contains implementations, notebooks, experiments, and project-level documentation across artificial intelligence, machine learning, computer vision, and natural language processing.

## Areas Covered

### Artificial Intelligence Fundamentals

- [Gogen Puzzle Solver](./01_artificial_intelligence_funtamentals/gogen_puzzle_solver): depth-first search and constraint satisfaction with look-ahead pruning.
- [Seven-Six Puzzle Solver](./01_artificial_intelligence_funtamentals/seven_six_puzzle): state-space search and puzzle-solving methods.

### Machine Learning

- [Classification and Regression](./02_machine_learning/01_Dataset%20adults%20and%20buston%20housing%20for%20classification%20and%20regression): supervised-learning workflows on tabular datasets.
- [Model Selection](./02_machine_learning/02_model_selection): model comparison and evaluation.
- [Neural Network from Scratch](./02_machine_learning/03_neural_network_from_scratch): NumPy implementation of feed-forward inference, backpropagation, and hyperparameter experiments.
- [Clustering and Anomaly Detection](./02_machine_learning/04_clustering%20and%20anomaly%20detection): unsupervised learning and outlier-detection methods.

### Computer Vision

- [Python and Computer Vision Foundations](./03_computer_vision/01_python%20in%20computer%20vision)
- [Canny Edge Detector](./03_computer_vision/02_canny_edge_detector)
- [Corner Detection and Image Stitching](./03_computer_vision/03_corners_detection_image_stitching)
- [Image Segmentation](./03_computer_vision/04_image_segmentation)
- [Sparse 3D Reconstruction](./03_computer_vision/05_sparse_3D_reconstruction): feature matching, RANSAC, epipolar geometry, pose recovery, and triangulation.

### Natural Language Processing

- [Twitter Text Pre-processing and Analysis](./04_natural_language_processing/01_Text_Pre-processing_and_Analysis_in_Twitter)
- [Twitter Sentiment Classification](./04_natural_language_processing/02_Twitter%20Sentiment%20Classification%20with%20NLP): BoW, TF-IDF, Word2Vec, GloVe, sentiment features, and classical classifiers.

## Technologies

Python, NumPy, Pandas, Scikit-learn, OpenCV, Matplotlib, NLTK, Gensim, Hugging Face datasets, and Jupyter notebooks.

Each project folder contains its own code and, where available, a dedicated README with setup instructions, methodology, experiments, and results.
